# Roadmap

For the next year (to the end of 2027), Matreshka.js 3 is maintained, not grown.

## Planned

- Bug fixes, each with a regression test, released as patches.
- Security fixes ([SECURITY.md](./SECURITY.md)).
- The same browsers as the latest jQuery, Internet Explorer 11 included, for all of 3.x.
- Dependency updates (Dependabot), the gates and CodeQL green on every change.
- Docs in English, Ukrainian and Russian, kept current with each release.

## Not planned

- A virtual DOM, components, JSX or templates compiled at build time.
- A required build step: the script tag stays a first-class way to use it.
- Server-side rendering.
- Runtime dependencies.
- Breaking changes within 3.x.
