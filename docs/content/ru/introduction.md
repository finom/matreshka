# Введение

Matreshka.js связывает JavaScript-объекты с HTML, который уже есть на странице. Вы привязываете свойство к DOM-узлу, и с этого момента они синхронизированы. Меняете свойство — обновляется узел; вводите текст в узел — меняется свойство. Без шаблонов, без виртуального DOM и без сборки.

## Как это работает

Привязка добавляет свойству геттер и сеттер. Присваивание `app.x = 'hi'` вызывает сеттер: он обновляет все узлы, привязанные к `x`, и генерирует событие `change:x`. Зависимые свойства, преобразование значений и коллекции построены на этом же механизме.

## Где она уместна

- Страницы, HTML которых приходит с сервера: сайты с серверным рендерингом, темы CMS, старые приложения. Matreshka добавляет поведение к этой разметке, не забирая её под свой контроль.
- Виджеты и отдельные HTML-файлы: один тег `<script>` с CDN, без npm и без сборщика.
- Существующий код: привязка работает с любым обычным объектом, поэтому её можно добавлять по частям.

## Что вы получаете

- Двустороннюю привязку к полям ввода, тексту, атрибутам и классам
- Зависимые свойства (`calc`) и преобразование значений (`mediate`)
- Списки, которые рендерят каждый элемент и остаются синхронизированными (`Matreshka.Array`)
- События изменений, в том числе для вложенных данных
- Роутер и парсер форм

Около 19 кБ в gzip, с типами TypeScript.

## Чем она не является

Компонентным фреймворком. В ней нет JSX, однофайловых компонентов и серверного рендеринга. Если вы пишете весь интерфейс на JavaScript с нуля, лучше подойдут React или Vue.
