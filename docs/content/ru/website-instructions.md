# Как использовать документацию

## Уровни важности
Документация разбита на три уровня "продвинутости".

### <span class="mk-circles" data-level="1" aria-hidden="true"><i></i></span> Первый уровень - самое важное
Изучив самые важные свойства и методы, вы можете смело приступать к работе. С классами, методами и свойствами, помеченными значком <span class="mk-circles" data-level="1" aria-hidden="true"><i></i></span> необходимо разобраться в первую очередь.

### <span class="mk-circles" data-level="2" aria-hidden="true"><i></i><i></i></span> Второй уровень - рекомендуется изучить
После того, как вы освоили необходимые для быстрого старта возможности, можете ознакомиться с другими, менее важными (но всё еще важными) свойствами и методами Matreshka.js.

### <span class="mk-circles" data-level="3" aria-hidden="true"><i></i><i></i><i></i></span> Третий уровень - остальные методы и свойства
Для того, чтоб не пугать новичков вещами, которые используются относительно редко, все неважные методы и свойства по умолчанию скрыты. Если вы хотите знать о фреймворке всё, без исключения, выберите <span class="mk-circles" data-level="3" aria-hidden="true"><i></i><i></i><i></i></span> на переключателе слева, в меню.

**Внимание**, если вы перейдете по ссылке к методу или свойству третьего уровня важности, то третий уровень включится автоматически.

## Опечатки и ошибки в документации

В конце каждой статьи документации есть ссылка на исходник статьи. Исправить опечатку или ошибку можно прямо в редакторе на Github.

> Документация разработана с использованием GitHub Flavored Markdown.

## Модули

Фреймворк - один пакет с тремя точками входа.

```js
import Matreshka from 'matreshka';
import { initRouter } from 'matreshka/router';
import { parseForm } from 'matreshka/parse-form';
```
