# Как пользоваться сайтом

## Всё сразу или по одному

Документация — это одна страница на каждый язык. В режиме **«Всё сразу»** видны все разделы: их можно листать подряд или искать по ним через Ctrl+F (⌘F). В режиме **«По одному»** виден только открытый раздел, а под ним — ссылки на предыдущий и следующий. Переключатель находится вверху меню, и сайт запоминает выбор.

## Уровни важности

API разделён на три уровня.

- **Первый — основа.** В меню отмечен точкой. Начните с него: этого достаточно, чтобы написать целое приложение.
- **Второй — рекомендуемое.** Остальная часть API, нужная каждый день.
- **Третий — для опытных.** Скрыт, пока в меню не включён режим **«Для опытных»**. На первых порах большинству приложений он не нужен.

Если открыть ссылку на раздел третьего уровня, режим «Для опытных» включится сам.

## Поиск

Поле вверху меню фильтрует его по названию, а Enter открывает первый найденный раздел. Клавиша `/` переводит курсор в это поле из любого места страницы. В режиме «Всё сразу» поиск браузера (Ctrl+F) находит текст во всех видимых разделах.

## Ссылки

У каждого раздела свой адрес, например `matreshka.js.org/ru/#Matreshka-bindNode`. Ссылки в старом формате (`#!Matreshka-bindNode`) по-прежнему работают.

## Ошибки и опечатки

В конце каждого раздела есть ссылка на его исходный файл на GitHub. Исправьте ошибку там или создайте issue.

## Тёмная тема

Сайт следует теме системы. Кнопка в верхней панели переключает светлую и тёмную тему.
