# class

**Тип**

Класс созданный при помощи синтаксиса ECMAScript 2015 либо возвращаемый функцией [`Matreshka.Class`](/ru/api/matreshka-static/class/)

## Примеры

```js
class MyClass {
	method() { ... }
};
```

```js
const MyClass = Matreshka.Class({
	method() { ... }
});
```
