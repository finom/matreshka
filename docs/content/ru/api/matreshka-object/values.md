# Matreshka.Object#values

**Метод** · Начиная с версии 2.0.0

```js
Matreshka.Object#values() → array
```

Возвращает массив значений свойств, отвечающих за данные

**Возвращает:** [`array`](/ru/api/types/array/) – values

## Примеры

```js
const values = this.values();
```
