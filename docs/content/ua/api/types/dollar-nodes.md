# $nodes

**Тип**

Масив DOM-елементів. Там, де метод очікує елементи, він прийме й будь-який масивоподібний об’єкт: NodeList, об’єкт jQuery.

## Приклади

```js
const $nodes = [...document.querySelectorAll('.foo')];
```
