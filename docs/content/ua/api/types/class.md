# class

**Тип**

Клас створений за допомогою синтаксису ECMAScript 2015 або повернений функцією [`Matreshka.Class`](/ua/api/matreshka-static/class/)

## Приклади

```js
class MyClass {
	method() { ... }
};
```

```js
const MyClass = Matreshka.Class({
	method() { ... }
});
```
