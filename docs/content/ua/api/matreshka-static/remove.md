# Matreshka.remove

**Метод** · Починаючи з версії 1.1

**Імпорт:**

```js
import remove from 'matreshka/remove';
```

```js
Matreshka.remove() → object
```

Видаляє властивість

Цей статичний метод працює так само, як і [`Matreshka#remove`](/ua/api/matreshka/remove/) та всі його варіації, але приймає в якості першого аргументу будь-який JavaScript об'єкт.

**Повертає:** [`object`](/ua/api/types/object/) – Перший аргумент

## Посилання

- [`Matreshka#remove`](/ua/api/matreshka/remove/)

## Приклади

```js
Matreshka.remove(object, 'x');
```
