# Як користуватися документацією

## Рівні важливості
Документація розбита на три рівні важливості.

### <span class="mk-circles" data-level="1" aria-hidden="true"><i></i></span> Перший рівень - найважливіше
Вивчивши найважливіші властивості і методи, ви можете сміливо приступати до роботи. З класами, методами і властивостями, поміченими значком <span class="mk-circles" data-level="1" aria-hidden="true"><i></i></span> необхідно розібратися в першу чергу.

### <span class="mk-circles" data-level="2" aria-hidden="true"><i></i><i></i></span> Другий рівень - рекомендується вивчити
Після того, як ви освоїли необхідні для швидкого старту можливості, можете ознайомитися з іншими, менш важливими (але все ще важливими) властивостями і методами фреймворку.

### <span class="mk-circles" data-level="3" aria-hidden="true"><i></i><i></i><i></i></span> Третій рівень - інші методи і властивості
Для того, щоб не лякати новачків речами, які використовуються відносно рідко, інші методи і властивості за замовчуванням приховані. Якщо ви хочете знати про фреймворк все, без винятку, оберіть <span class="mk-circles" data-level="3" aria-hidden="true"><i></i><i></i><i></i></span> на перемикачі зліва, в меню.

**Увага**, якщо ви перейдете по посиланню до методу або властивості третього рівня важливості, то третій рівень увімкнеться автоматично.

## Помилки в документації

У кінці кожної статті документації є посилання на код цієї статті. Виправити помилку можна прямо в редакторі на Github.

> Документація розроблена з використанням GitHub Flavored Markdown.

## Модулі

Фреймворк - один пакет з трьома точками входу.

```js
import Matreshka from 'matreshka';
import { initRouter } from 'matreshka/router';
import { parseForm } from 'matreshka/parse-form';
```
