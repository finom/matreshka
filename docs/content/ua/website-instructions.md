# Як користуватися сайтом

## Усе одразу або по одному

Документація — це одна сторінка для кожної мови. У режимі **«Усе одразу»** видно всі розділи: їх можна гортати поспіль або шукати в них через Ctrl+F (⌘F). У режимі **«По одному»** видно лише відкритий розділ, а під ним — посилання на попередній і наступний. Перемикач розташований угорі меню, і сайт запам’ятовує вибір.

## Рівні важливості

API поділено на три рівні.

- **Перший — основа.** У меню позначений крапкою. Почніть із нього: цього досить, щоб написати цілий застосунок.
- **Другий — рекомендоване.** Решта API, потрібна щодня.
- **Третій — для досвідчених.** Прихований, доки в меню не ввімкнено режим **«Для досвідчених»**. На початку більшості застосунків він не потрібен.

Якщо відкрити посилання на розділ третього рівня, режим «Для досвідчених» увімкнеться сам.

## Пошук

Поле вгорі меню фільтрує його за назвою, а Enter відкриває перший знайдений розділ. Клавіша `/` переводить курсор у це поле з будь-якого місця сторінки. У режимі «Усе одразу» пошук браузера (Ctrl+F) знаходить текст у всіх видимих розділах.

## Посилання

Кожен розділ має власну адресу, наприклад `matreshka.js.org/ua/#Matreshka-bindNode`. Посилання в старому форматі (`#!Matreshka-bindNode`) і далі працюють.

## Помилки й описки

Наприкінці кожного розділу є посилання на його вихідний файл на GitHub. Виправте помилку там або створіть issue.

## Темна тема

Сайт дотримується теми системи. Кнопка у верхній панелі перемикає світлу й темну тему.
