# Вступ

Matreshka.js поєднує JavaScript-об’єкти з HTML, який уже є на сторінці. Ви прив’язуєте властивість до DOM-вузла, і відтепер вони синхронізовані. Змінюєте властивість — оновлюється вузол; вводите текст у вузол — змінюється властивість. Без шаблонів, без віртуального DOM і без збирання.

## Як це працює

Прив’язка додає властивості геттер і сеттер. Присвоєння `app.x = 'hi'` викликає сеттер: він оновлює всі вузли, прив’язані до `x`, і генерує подію `change:x`. Залежні властивості, перетворення значень і колекції побудовані на цьому ж механізмі.

## Де вона доречна

- Сторінки, HTML яких приходить із сервера: сайти із серверним рендерингом, теми CMS, старі застосунки. Matreshka додає поведінку до цієї розмітки, не забираючи її під свій контроль.
- Віджети та окремі HTML-файли: один тег `<script>` із CDN, без npm і без збирача.
- Наявний код: прив’язка працює з будь-яким звичайним об’єктом, тож її можна додавати частинами.

## Що ви отримуєте

- Двосторонню прив’язку до полів введення, тексту, атрибутів і класів
- Залежні властивості (`calc`) і перетворення значень (`mediate`)
- Списки, що рендерять кожен елемент і лишаються синхронізованими (`Matreshka.Array`)
- Події змін, зокрема для вкладених даних
- Роутер і парсер форм

Близько 24 кБ у gzip, з типами TypeScript.

## Чим вона не є

Компонентним фреймворком. У ній немає JSX, однофайлових компонентів і серверного рендерингу. Якщо ви пишете весь інтерфейс на JavaScript з нуля, краще підійдуть React або Vue.
