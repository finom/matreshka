# Matreshka#once

**Метод** · Починаючи з версії 1.1

```js
Matreshka#once(names, callback, [context]) → object
```

Додає обробник подій, який може бути викликаний один раз

Метод працює так само, як і [`Matreshka#on`](/ua/api/matreshka/on/) але переданий обробник може бути викликаний тільки один раз.

> Зверніть увагу, що у метода є [статичний аналог](/ua/api/matreshka-static/once/)

**Повертає:** [`object`](/ua/api/types/object/) – self

**Генерує події:** `addevent`, `addevent:NAME`

## Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `names` | [`eventNames`](/ua/api/types/event-names/) | Ім'я події або кілька імен, розділених пробілом (наприклад, \<code>"change:x ajaxcomplete change:y" \</code>) |
| `callback` | [`eventHandler`](/ua/api/types/event-handler/) | Функція, яка викликається за подією |
| `context` (необов'язковий) | [`object`](/ua/api/types/object/) | Контекст обробника |

## Посилання

- [`Matreshka#on`](/ua/api/matreshka/on/)

## Приклади

```js
this.x = 1;

this.once('change:x', () => {
	alert('x is changed');
});

this.x = 2; // виводить 'x is changed'

this.x = 3; // нічого не робить
```

## Альтернативний синтаксис: пари "подія-обробник" [#variation-2]

```js
Matreshka#once(evtnameHandlerObject, [context]) → object
```

У метод [`Matreshka#once`](/ua/api/matreshka/once/) можна передати об'єкт з парами подія-обробник, щоб уникнути багаторазового виклику методу і скоротити код.

**Повертає:** [`object`](/ua/api/types/object/) – self

### Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `evtnameHandlerObject` | [`object`](/ua/api/types/object/) | Об'єкт з подіями |
| `context` (необов'язковий) | [`object`](/ua/api/types/object/) | Контекст обробників |

### Посилання

- [`Matreshka#on(2)`](/ua/api/matreshka/on/#variation-2)

### Приклади

```js
this.once({
	'custom': evt => { ... },
	'click::x': evt => { ... },
	'change:y': evt => { ... }
});
```
