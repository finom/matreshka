# Matreshka#off

**Метод**

```js
Matreshka#off([names], [callback], [context]) → matreshka
```

Видаляє обробник події

Видаляє створений раніше обробник. Всі три аргументи опційні. Ви можете видалити як всі події (не передаючи жодного аргументу), так і окремі (передавши тільки ім'я події, передавши ім'я події і обробник, передавши і ім'я події, і обробник, і контекст)

Без аргументів ``off`` видаляє всі обробники, додані через ``on``, ``once`` і ``onDebounce``, і генерує ``removeevent`` для кожного з них. Прив'язки, залежності ``calc`` і внутрішні події ``Matreshka.Object`` та ``Matreshka.Array`` залишаються.

**Повертає:** [`matreshka`](/ua/api/types/matreshka/) – self

**Генерує події:** `removeevent`, `removeevent:NAME`

## Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `names` (необов'язковий) | [`eventNames`](/ua/api/types/event-names/) | Розділений пробілами список імен подій (наприклад, ``"change:x ajaxcomplete change:y"``) |
| `callback` (необов'язковий) | [`eventHandler`](/ua/api/types/event-handler/) | Функція-обробник |
| `context` (необов'язковий) | [`object`](/ua/api/types/object/) | Контекст |

## Приклади

```js
this.off('change:x bind');
```

**Видалення всіх подій**

```js
this.off();
```

**Видалення події з певним обробником**

```js
const handler = function () {
	// ...
}
this.on('change:x', handler);
this.off('change:x', handler);
```

**Видалення події з певним контекстом**

```js
const object = {};
this.on('change:x', handler, object);
this.off('change:x', handler, object);
```
