# Matreshka#isMatreshka

**Властивість**

<Advanced>Для досвідчених користувачів: на початку це зазвичай не потрібно.</Advanced>

```js
Matreshka#isMatreshka: boolean
```

``isMatreshka`` завжди дорівнює ``true`` для экземплярів [`Matreshka`](/ua/api/matreshka/)

## Приклади

```js
alert(object.isMatreshka);
```
