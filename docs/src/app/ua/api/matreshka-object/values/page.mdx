# Matreshka.Object#values

**Метод** · Починаючи з версії 2.0.0

<Advanced>Для досвідчених користувачів: на початку це зазвичай не потрібно.</Advanced>

```js
Matreshka.Object#values() → array
```

Повертає масив значень властивостей, що відповідають за дані

**Повертає:** [`array`](/ua/api/types/array/) – values

## Приклади

```js
const values = this.values();
```
