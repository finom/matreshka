# Matreshka.Object#keys

**Метод**

```js
Matreshka.Object#keys() → array
```

Повертає масив імен властивостей, що відповідають за дані

**Повертає:** [`array`](/ua/api/types/array/) – keys

## Приклади

```js
const keys = this.keys();
```
