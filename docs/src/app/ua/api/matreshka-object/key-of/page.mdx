# Matreshka.Object#keyOf

**Метод**

```js
Matreshka.Object#keyOf() → string|null
```

Шукає задане значення властивості серед властивостей, що відповідають за дані, і повертає ім'я властивості, якщо таке значення знайдено

**Повертає:** [`string`](/ua/api/types/string/) \| [`null`](/ua/api/types/null/) – перше знайдене ім'я властивості

## Властивості

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `value` | [`*`](/ua/api/types/any/) | значення будь-якого типу, яке слід знайти серед даних |

## Приклади

```js
const matreshkaObject = new Matreshka.Object({
	a: 1,
	b: 2
});

matreshkaObject.c = 3;

matreshkaObject.keyOf(1); // 'a'

matreshkaObject.keyOf(2); // 'b'

matreshkaObject.keyOf(3); // null
```
