# Matreshka.Object#addDataKeys

**Метод**

```js
Matreshka.Object#addDataKeys(keys) → matreshkaObject
```

Додає задані імена властивостей в список імен властивостей, що відповідають за дані

Цей метод застосовується тоді, коли потрібно оголосити властивості, що відповідають за дані, але значення цих властивостей ще не відомі.

**Повертає:** [`matreshkaObject`](/ua/api/types/matreshka-object/) – self

**Генерує події:** `set`, `modify`

## Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `keys` | [`string`](/ua/api/types/string/) \| [`array`](/ua/api/types/array/) | Масив імен властивостей або список аргументів з іменами властивостей |

## Приклади

```js
this.addDataKeys(['a', 'b']);
```

```js
this.addDataKeys('a', 'b');
```
