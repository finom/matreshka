# Matreshka.binders.attr

**Метод** · Починаючи з версії 0.3

**Імпорт:**

```js
import { binders } from 'matreshka';
// binders.attr === Matreshka.binders.attr
```

```js
Matreshka.binders.attr(attribute, [mappingFn]) → binder
```

Повертає байндер, який змінює атрибут DOM елемента на значення властивості об'єкту

Значення властивості можна перетворити за допомогою переданої функції ``mappingFn``.

``undefined`` і ``null`` встановлюють порожній атрибут; атрибут не видаляється.

**Повертає:** [`binder`](/ua/api/types/binder/)

## Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `attribute` | [`string`](/ua/api/types/string/) | Ім'я атрибута |
| `mappingFn` (необов'язковий) | [`function`](/ua/api/types/function/) | Відображаюча функція |

## Приклади

```js
this.bindNode('image', 'img.my-image', Matreshka.binders.attr('src'));

this.image = 'http://example.com/cats.jpg';
```

**Використання ``mappingFn``**

```js
this.bindNode('myKey', '.my-node',
    Matreshka.binders.attr('foo', value => `Hello, ${value}`));

this.myKey = 'World'; // атрибут foo має значення "Hello, World"
```
