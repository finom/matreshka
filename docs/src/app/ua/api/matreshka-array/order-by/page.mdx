# Matreshka.Array#orderBy

**Метод** · Починаючи з версії 1.6

```js
Matreshka.Array#orderBy(keys, [orders=asc]) → matreshkaArray
```

Сортує масив за значеннями властивостей об'єктів, які в нього входять

Цей метод працює майже так само, як і метод [orderBy з lodash](https://lodash.com/docs#orderBy). Він приймає ключ або масив ключів першим аргументом, порядок (asc/desc) або масив порядків - другим.

**Повертає:** [`matreshkaArray`](/ua/api/types/matreshka-array/) – self

**Генерує події:** `sort`

## Аргументи

| Ім'я | За замовчуванням | Тип | Опис |
| --- | --- | --- | --- |
| `keys` |  | [`string`](/ua/api/types/string/) \| [`array`](/ua/api/types/array/) | Ключ властивості або масив декількох ключів, за якими колекція буде відсортована |
| `orders` (необов'язковий) | `asc` | [`string`](/ua/api/types/string/) \| [`array`](/ua/api/types/array/) | Порядок або масив порядків, відповідних до масиву ключів |

## Приклади

```js
this.recreate([
    { 'user': 'fred',   'age': 48 },
    { 'user': 'barney', 'age': 34 },
    { 'user': 'fred',   'age': 42 },
    { 'user': 'barney', 'age': 36 }
]);

// сортує за значенням властивості 'user' по зростанню і значенням властивості 'age' по спаданню
this.orderBy(['user', 'age'], ['asc', 'desc']);
// → [{"user":"barney","age":36},{"user":"barney","age":34},{"user":"fred","age":48},{"user":"fred","age":42}]
```
