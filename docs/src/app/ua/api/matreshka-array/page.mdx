# Matreshka.Array

**Клас** · extends `Matreshka`

**Імпорт:**

```js
import { MatreshkaArray } from 'matreshka';
```

Клас ``Matreshka.Array`` служить колекцією в Matreshka.js. Він успадковується від класу [`Matreshka`](/ua/api/matreshka/) і включає всі його властивості та методи. Крім цього, ``Matreshka.Array`` має всі методи, які є у звичайного масиву, тим самим спрощуючи вивчення його можливостей.

#### Всі методи, запозичені у вбудованого Array працюють аналогічно їх оригіналам

Програміст, знайомий з методами нативного `` Array`` відразу може зрозуміти, яким методом можна додати елемент (``push``, ``unshift``, ``splice``), яким видалити (``pop``, ``shift``, ``splice``), яким впорядкувати (``sort``, ``reverse``) тощо.

У зв'язку з тим, що методи працюють так само, як і оригінальні (з невеликими винятками), вони не приведені в цій документації окремо, а виведені в розділ [`Matreshka.Array#METHOD`](/ua/api/matreshka-array/method/).
```js
this.push(1, 2, 3);
this.pop();
```

#### Всі методи, запозичені у вбудованого Array, які модифікують масив можуть бути викликані з передачею об'єкта події

Для цього використовується синтаксис ``метод_``, де нижнє підкреслення в кінці імені методу означає, що останнім аргументом є об'єкт події. Такі методи не наведено в цій документації, так як потрібно запам'ятати тільки їх синтаксис. Див. [`Matreshka.Array#METHOD_`](/ua/api/matreshka-array/method-silent/).
```js
this.push_(1, 2, 3, {
	silent: true
});

this.pop_({
	foo: 'bar'
});
```

#### Розробник має можливість відловлювати будь-які модифікації даних

__При використанні методів, запозичених у вбудованого ``Array`` генеруються події з відповідним ім'ям.__ Викликаючи метод ``push``, генерується подія ``push``, викликаючи метод ``shift`` генерується подія ``shift``, викликаючи метод ``sort``, генерується подія ``sort`` і так далі.
```js
this.on('push', evt => {
	console.log('push is called');
});

this.push(1, 2, 3);
```

__При додаванні елементів генеруються події ``add`` і ``addone``.__ Перше генерується один раз на додавання (наприклад, ви додали кілька елементів за допомогою ``push``, подія викликана лише один раз), друге генерується один раз на кожен доданий елемент.

При спрацьовуванні події ``add``, значенням властивості ``added`` об'єкта події передається масив доданих елементів, а при спрацьовуванні ``addone``, значенням властивості ``addedItem`` - кожен окремий доданий елемент.

```js
this.on('add', evt => {
	console.log(evt.added); // [1,2,3]
});

this.push(1, 2, 3);
```
```js
// Обробник запуститься тричі,
// так як в масив додали три нові елементи
this.on('addone', evt {
	console.log(evt.addedItem); // 1 ... 2 ... 3
});

this.push(1, 2, 3);
```


__При видаленні елементів діє та ж логіка__: ``remove`` спрацьовує один раз, навіть якщо видалено кілька елементів, а подія ``removeone`` спрацьовує для кожного віддаленого елемента індивідуально. При генерації події ``remove`` вилучені елементи містяться у властивості ``removed`` об'єкта події, а при генерації події ``removeone`` - кожен віддалений елемент міститься у властивості ``removedItem``.
```js
this.push(1, 2, 3, 4, 5);

this.on('remove', evt => {
	console.log(evt.removed); // [2, 3, 4]
});

this.splice(1, 3);
```
```js
this.push(1, 2, 3, 4, 5);

// Обробник запуститься тричі,
// так як з масиву видалили три елементи
this.on('removeone', evt => {
	console.log(evt.removedItem); // 2 ... 3 ... 4
});

this.splice(1, 3);
```

__Приі кожної модифікації масиву генерується подія ``modify``__, дозволяючи відловити всі без винятку зміни в масиві (додавання, видалення, пересортовування).
```js
this.on('modify', evt => {
	console.log(evt.added);
	console.log(evt.removed);
});
```

__``length`` - це звичайне свойство__ яке можна пов'язувати з HTML елементом або відловлювати зміни за допомогою події ``change:length``.

> Наприклад, при додаванні трьох елементів за допомогою методу ``push``, генеруються наступні події: ``push``, ``add``, ``addone`` (тричі), ``modify``, ``change:length``.

#### Model
Властивість [`Matreshka.Array#Model`](/ua/api/matreshka-array/model/) визначає клас елементів, які буде містити колекція. Рекомендується наслідувати ``Model`` від класу [`Matreshka.Object`](/ua/api/matreshka-object/) або [`Matreshka.Array`](/ua/api/matreshka-array/) (на випадок, якщо потрібно отримати колекцію колекцій), щоб отримати можливість конвертації масиву в звичайний масив рекурсивно методом [`Matreshka.Array#toJSON`](/ua/api/matreshka-array/to-json/).

#### Автоматичний рендеринг
``Matreshka.Array`` вміє автоматично відмальовувати елементи на сторінці при будь-яких модифікаціях масиву. За подробицями зверніться до документації [`Matreshka.Array#itemRenderer`](/ua/api/matreshka-array/item-renderer/).

## Приклади

**Створення екземпляра з нульовою довжиною**

```js
new Matreshka.Array();
```

**Створення екземпляра із зазначенням довжини**

```js
new Matreshka.Array(42);
```

Як і нативний ``Array``, одне число, яке не є допустимою довжиною (від'ємне, дробове або ``NaN``), кидає ``RangeError``.

**Передача елементів при створенні**

```js
new Matreshka.Array('Hi', { a: 'b' });
```

**Спадкування**

```js
class MyClass extends Matreshka.Array {
	constructor(items) {
		super(...items).sayHello();
	}
	sayHello() {
		alert("Hello World!");
	}
}
```

**Спадкування, використовуючи функцію [`Matreshka.Class`](/ua/api/matreshka-static/class/)**

```js
const MyClass = Matreshka.Class({
	extends: Matreshka.Array,
	constructor(items) {
		this.recreate(items).sayHello();
	},
	sayHello() {
		alert("Hello World!");
	}
});
```

## Властивості й методи

- [`METHOD`](/ua/api/matreshka-array/method/) – Будь-який метод iз ``Array.prototype``
- [`METHOD_`](/ua/api/matreshka-array/method-silent/) – Будь-який метод iз ``Array.prototype`` з можливістю передати об'єкт події
- [`Model`](/ua/api/matreshka-array/model/) – Властивість визначає клас елементів, які буде містити колекція
- [`isMatreshkaArray`](/ua/api/matreshka-array/is-matreshka-array/) _(для досвідчених)_ – ``isMatreshkaArray`` завжди дорівнює ``true`` для экземплярів [`Matreshka.Array`](/ua/api/matreshka-array/)
- [`itemRenderer`](/ua/api/matreshka-array/item-renderer/) – HTML строка, селектор або функція, яка відповідає за рендерінг элементів масива на сторінці
- [`mediateItem`](/ua/api/matreshka-array/mediate-item/) – Трансформує значення елементів масиву
- [`onItemRender`](/ua/api/matreshka-array/on-item-render/) – Функція, яка запускається перед подією ``render``.
- [`orderBy`](/ua/api/matreshka-array/order-by/) – Сортує масив за значеннями властивостей об'єктів, які в нього входять
- [`pull`](/ua/api/matreshka-array/pull/) – Видаляє елемент за індексом або за значенням
- [`recreate`](/ua/api/matreshka-array/recreate/) – Перестворює екземпляр [`Matreshka.Array`](/ua/api/matreshka-array/)
- [`renderIfPossible`](/ua/api/matreshka-array/render-if-possible/) _(для досвідчених)_ – Властивість ``renderIfPossible`` скасовує рендеринг масиву якщо має значення `` false``
- [`rerender`](/ua/api/matreshka-array/rerender/) _(для досвідчених)_ – Перемальовує DOM вузли об'єктів, що входять в масив
- [`restore`](/ua/api/matreshka-array/restore/) – Відтворює [`Matreshka.Array`](/ua/api/matreshka-array/) з HTML вузлів на сторінці.
- [`toJSON`](/ua/api/matreshka-array/to-json/) – Конвертує екземпляр [`Matreshka.Array`](/ua/api/matreshka-array/) в звичайний масив
- [`trackBy`](/ua/api/matreshka-array/track-by/) – Властивість ``trackBy`` вказує на ім'я властивості ідентифікатора об'єктів, що входять в масив
- [`from`](/ua/api/matreshka-array/from/) – Метод створює новий екземпляр [`Matreshka.Array`](/ua/api/matreshka-array/) з масивоподібного або ітеруємого об'єкта
- [`of`](/ua/api/matreshka-array/of/) – Метод створює новий екземпляр [`Matreshka.Array`](/ua/api/matreshka-array/) з довільного числа агрумент, незалежно від числа або типу аргументів
