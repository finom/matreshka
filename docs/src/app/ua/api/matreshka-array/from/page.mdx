# Matreshka.Array.from

**Метод** · Починаючи з версії 1.1

```js
Matreshka.Array.from(arrayLike, [mapFn], [thisArg]) → matreshkaArray
```

Метод створює новий екземпляр [`Matreshka.Array`](/ua/api/matreshka-array/) з масивоподібного або ітеруємого об'єкта

**Повертає:** [`matreshkaArray`](/ua/api/types/matreshka-array/)

## Аргументи

| Ім'я | Тип | Опис |
| --- | --- | --- |
| `arrayLike` | [`object`](/ua/api/types/object/) | Массивоподібний або ітеруємий об'єкт |
| `mapFn` (необов'язковий) | [`function`](/ua/api/types/function/) | Відображаюча функція, що викликається для кожного елемента масиву |
| `thisArg` (необов'язковий) | [`*`](/ua/api/types/any/) | Об'єкт, який використовується в якості ``this`` при виклику ``mapFn`` |

## Посилання

- [Array.from](https://developer.mozilla.org/en/docs/Web/JavaScript/Reference/Global_Objects/Array/from)

## Приклади

```js
const matreshkaArray = Matreshka.Array.from([1, 2, 3, 4]);
```

```js
const matreshkaArray = Matreshka.Array.from([1, 2, 3, 4], item => item * 2);
```

**Спадкування методу**

```js
class MyClass extends Matreshka.Array {
    // ...
}

const myArray = MyClass.from([1, 2, 3, 4]);
console.log(myArray instanceof MyClass); // true
```
