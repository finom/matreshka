# Matreshka.Object#keys

**Метод**

```js
Matreshka.Object#keys() → array
```

Возвращает массив имен свойств, отвечающих за данные

**Возвращает:** [`array`](/ru/api/types/array/) – keys

## Примеры

```js
const keys = this.keys();
```
