# Matreshka.Object#toJSON

**Метод**

```js
Matreshka.Object#toJSON([recursive=true]) → object
```

Конвертирует экземпляр [`Matreshka.Object`](/ru/api/matreshka-object/) в обычный объект

Метод работает рекурсивно, вызывая ``toJSON`` для всех свойств, у которых есть метод с таким именем. Для отмены рекурсии передайте ``false`` первым аргументом.

**Возвращает:** [`object`](/ru/api/types/object/)

## Аргументы

| Имя | По умолчанию | Тип | Описание |
| --- | --- | --- | --- |
| `recursive` (необязательный) | `true` | [`boolean`](/ru/api/types/boolean/) |  |

## Примеры

```js
const matreshkaObject = new Matreshka.Object({
	a: 1,
	b: 2,
	c: new Matreshka.Object({
		d: 3,
		e: 4
	})
});

// возвращает {a: 1, b: 2, c: { d: 3, e: 4 }}
console.log(matreshkaObject.toJSON());

// возвращает {a: 1, b: 2, c: MatreshkaObject}
console.log(matreshkaObject.toJSON(false));
```
