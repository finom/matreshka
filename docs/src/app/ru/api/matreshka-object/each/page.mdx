# Matreshka.Object#each

**Метод**

```js
Matreshka.Object#each(callback, [thisArg]) → matreshkaObject
```

Перебирает свойства, отвечающие за данные

Метод очень похож на ``Array.prototype.forEach`` и является альтернативой циклу for..of.

**Возвращает:** [`matreshkaObject`](/ru/api/types/matreshka-object/) – self

## Аргументы

| Имя | Тип | Описание |
| --- | --- | --- |
| `callback` | [`function`](/ru/api/types/function/) | Функция, которая вызывается на каждой итерации |
| `thisArg` (необязательный) | [`*`](/ru/api/types/any/) | Контекст функции |

## Примеры

```js
this
	.setData({ a: 1, b: 2 })
	.addDataKeys('c')
	.each((value, key) => {
		console.log(key, value);
	});
;
// >>> a 1, b 2, c undefined
```
