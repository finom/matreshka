# Matreshka.Object#isMatreshkaObject

**Свойство**

<Advanced>Для опытных пользователей: на первых порах это обычно не нужно.</Advanced>

```js
Matreshka.Object#isMatreshkaObject: boolean
```

Свойство ``isMatreshkaObject`` всегда равно ``true`` для экземпляров [`Matreshka.Object`](/ru/api/matreshka-object/).

## Примеры

```js
console.log(object.isMatreshkaObject);
```
