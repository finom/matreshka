# Matreshka#isMatreshka

**Свойство**

<Advanced>Член для продвинутых: на старте он редко нужен.</Advanced>

```js

```

``isMatreshka`` всегда равен ``true`` для экземпляров [`Matreshka`](/ru/api/matreshka/)
