# Matreshka.Array.from

**Метод** · Начиная с версии 1.1

```js
Matreshka.Array.from(arrayLike, [mapFn], [thisArg]) → matreshkaArray
```

Метод создаёт новый экземпляр [`Matreshka.Array`](/ru/api/matreshka-array/) из массивоподобного или итерируемого объекта

**Возвращает:** [`matreshkaArray`](/ru/api/types/matreshka-array/)

## Аргументы

| Имя | Тип | Описание |
| --- | --- | --- |
| `arrayLike` | [`object`](/ru/api/types/object/) | Массивоподобный или итерируемый объект |
| `mapFn` (необязательный) | [`function`](/ru/api/types/function/) | Отображающая функция, вызываемая для каждого элемента массива |
| `thisArg` (необязательный) | [`*`](/ru/api/types/any/) | Объект, который используется в качестве ``this`` при вызове ``mapFn`` |

## Ссылки

- [Array.from](https://developer.mozilla.org/en/docs/Web/JavaScript/Reference/Global_Objects/Array/from)

## Примеры

```js
const matreshkaArray = Matreshka.Array.from([1, 2, 3, 4]);
```

```js
const matreshkaArray = Matreshka.Array.from([1, 2, 3, 4], item => item * 2);
```

**Наследование метода**

```js
class MyClass extends Matreshka.Array {
    // ...
}

const myArray = MyClass.from([1, 2, 3, 4]);
console.log(myArray instanceof MyClass); // true
```
