# $nodes

**Тип**

Массив DOM-элементов. Там, где метод ожидает элементы, он примет и любой массивоподобный объект: NodeList, объект jQuery.

## Примеры

```js
const $nodes = [...document.querySelectorAll('.foo')];
```
