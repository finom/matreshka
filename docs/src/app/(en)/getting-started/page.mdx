# Getting started

## Installation

```sh
npm install matreshka
```

```js
import Matreshka from 'matreshka';
// or, with CommonJS
const Matreshka = require('matreshka');
```

The router and the form parser are separate packages: [matreshka-router](https://github.com/finom/matreshka/tree/main/packages/router) binds properties to parts of the URL, [matreshka-parse-form](https://github.com/finom/matreshka/tree/main/packages/parse-form) binds named form fields to properties.

`initRouter(object, '/a/b/')` keeps `object.a` and `object.b` in sync with the parts of `location.hash` after `#!` (`#!/foo/bar/`); the values are encoded in the URL and decoded in the properties. Pass `'history'` as the third argument to use the path through the History API instead. `parseForm(object, form)` returns the form, or `null` when the form isn't found.

```sh
npm install matreshka-router matreshka-parse-form
```

### A script tag

Without a bundler, load the browser bundle. It defines the global `Matreshka` and its short alias `MK`. The bundles target current browsers.

```html
<script src="https://cdn.jsdelivr.net/npm/matreshka@2/dist/matreshka.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/matreshka-router@2/dist/matreshka-router.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/matreshka-parse-form@2/dist/matreshka-parse-form.min.js"></script>
```

This site serves the same files: [/matreshka.min.js](/matreshka.min.js), [/matreshka-router.min.js](/matreshka-router.min.js) and [/matreshka-parse-form.min.js](/matreshka-parse-form.min.js). The router adds `Matreshka.initRouter` and `Matreshka.Router` to the global `Matreshka`, the form parser adds `Matreshka.parseForm`.

## Modules

Every static function or class can be imported as a module, which keeps a bundle small. Each page of the API reference shows the path of its module.

```js
import MatreshkaArray from 'matreshka/array';
import bindNode from 'matreshka/bindnode';
import { prop } from 'matreshka/binders';
```

CommonJS gets the same modules with `require`:

```js
const bindNode = require('matreshka/bindnode');
```

The import of the main module pulls the entire framework.

```js
import Matreshka from 'matreshka';
```

> A pure module of the [`Matreshka`](/api/matreshka/) class (without `binders`, `Array` and `Object`) lives at `'matreshka/matreshka'`.

## Importance levels

The API is split up into three parts.

### The first level: the most important stuff

After you've learned the most important API parts you can hardily start doing fantastic things. Start with [`Matreshka#bindNode`](/api/matreshka/bind-node/), [`Matreshka#calc`](/api/matreshka/calc/), [`Matreshka#on`](/api/matreshka/on/), [`Matreshka.Object`](/api/matreshka-object/) and [`Matreshka.Array`](/api/matreshka-array/).

### The second level: recommended to learn

If you already know the quick-start basics, you can look at less important (but still important) methods and properties of the framework.

### The third level: other methods and properties

Rarely used members are marked "Advanced" and listed last in each section of the sidebar. Read them when you want to know everything about Matreshka.js.
