# Matreshka.Array#Model

**Method** · Since 0.2 · Defined by you

```js
Matreshka.Array#Model(data, matreshkaArray, index)
```

The property defines a class of items which will be inserted to a collection

Every time items are added to an array, the built-in handler checks if added item is ``Model`` instance and converts it into the one if the check fails. It is recommended to inherit ``Model`` from the [`Matreshka.Object`](/api/matreshka-object/) or [`Matreshka.Array`](/api/matreshka-array/) class (in case if it is necessary to get a collection of collections) to get an opportunity of an array conversion into ordinary one by [`Matreshka.Array#toJSON`](/api/matreshka-array/to-json/) method.

Use [`Matreshka.Array#mediateItem`](/api/matreshka-array/mediate-item/) for more flexible control of an item class (for example, if you need to use one class for certain items and another one - for others).

``Model`` can be declared as a class field (``Model = MyModel;``) as well as a getter. Class fields are set after ``super(...)`` returns, so the items passed to ``super(...)`` are converted when a method next changes the array; a ``get Model()`` getter converts them right away.

Changing ``Model`` later converts the items the array already has and replaces their rendered nodes.

## Arguments

| Name | Type | Details |
| --- | --- | --- |
| `data` | [`object`](/api/types/object/) | Data which have been passed to a constructor |
| `matreshkaArray` | [`matreshkaArray`](/api/types/matreshka-array/) | An array where an item has been added to |
| `index` | [`number`](/api/types/number/) | Current index of an instance in the parent array |

## Examples

```js
// define a model
class MyModel extends Matreshka.Object {
	constructor(data, parentArray, index) {
		super(data);
		this.doSomething();
	}
	doSomething() { ... }
}

// define collection class
class MyArray extends Matreshka.Array {
	get Model() {
		return MyModel;
	}
}

const myArray = new MyArray();

// add two items
myArray.push({
    a: 1,
    b: 2
}, {
    a: 3,
    b: 4
});

console.log(myArray[0] instanceof MyModel); // true
console.log(myArray[1] instanceof MyModel); // true

// returns [{ a: 1, b: 2 }, { a: 3, b: 4 }]
myArray.toJSON();
```
