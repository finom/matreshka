# Matreshka.binders.attr

**Method** · Since 0.3

**Import:**

```js
import attr from 'matreshka/binders/attr';
// or
import { attr } from 'matreshka/binders';
```

```js
Matreshka.binders.attr(attribute, [mappingFn]) → binder
```

Returns a binder which changes an attribute of DOM node depending on an object property value

The value can be transformed using ``mappingFn`` argument.

``undefined`` and ``null`` set an empty attribute; the attribute is not removed.

**Returns:** [`binder`](/api/types/binder/)

## Arguments

| Name | Type | Details |
| --- | --- | --- |
| `attribute` | [`string`](/api/types/string/) | Attribute name |
| `mappingFn` (optional) | [`function`](/api/types/function/) | Mapping function |

## Examples

```js
this.bindNode('image', 'img.my-image', Matreshka.binders.attr('src'));

this.image = 'http://example.com/cats.jpg';
```

**The usage of mapping function**

```js
this.bindNode('myKey', '.my-node',
    Matreshka.binders.attr('foo', value => `Hello, ${value}`));

this.myKey = 'World'; // the foo attr now has value "Hello, World"
```
