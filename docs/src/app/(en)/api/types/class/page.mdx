# class

**Type**

A class made using ECMAScript 2015 syntax or returned by [`Matreshka.Class`](/api/matreshka-static/class/) function

## Examples

```js
class MyClass {
	method() { ... }
};
```

```js
const MyClass = Matreshka.Class({
	method() { ... }
});
```
