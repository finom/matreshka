# Matreshka.Object#each

**Method**

```js
Matreshka.Object#each(callback, [thisArg]) → matreshkaObject
```

Iterates properties which are responsible for data through ``callback`` function

This method is very similar to ``Array.prototype.forEach``. It allows to iterate over data properties when for..of syntax is not available.

**Returns:** [`matreshkaObject`](/api/types/matreshka-object/) – self

## Arguments

| Name | Type | Details |
| --- | --- | --- |
| `callback` | [`function`](/api/types/function/) | A function which is called on every iteration |
| `thisArg` (optional) | [`*`](/api/types/any/) | A context of a function |

## Examples

```js
this
	.setData({ a: 1, b: 2 })
	.addDataKeys('c')
	.each((value, key) => {
		console.log(key, value);
	}, this);
;
// >>> a 1, b 2, c undefined
```
