# Matreshka.calc

**Method** · Since 1.1

<Advanced>An advanced member: you rarely need it to start with.</Advanced>

**Import:**

```js
import calc from 'matreshka/calc';
```

```js
Matreshka.calc() → object
```

Creates a dependency of one property value on values of others

This static method works the same as [`Matreshka#calc`](/api/matreshka/calc/) and all its variations, but accepts any kind of JavaScript object as first argument.

**Returns:** [`object`](/api/types/object/) – The first argument

## Links

- [`Matreshka#calc`](/api/matreshka/calc/)

## Examples

```js
const object = {};
object.a = 40;
object.b = 2;
Matreshka.calc(object, 'sum', ['a', 'b'], (a, b) => a + b);
alert(object.sum); // 42
```
