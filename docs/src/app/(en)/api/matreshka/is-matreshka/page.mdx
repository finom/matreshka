# Matreshka#isMatreshka

**Property**

<Advanced>For advanced use: most apps don't need it at first.</Advanced>

```js
Matreshka#isMatreshka: boolean
```

``isMatreshka`` always equals ``true`` for instances of [`Matreshka`](/api/matreshka/)

## Examples

```js
alert(object.isMatreshka);
```
