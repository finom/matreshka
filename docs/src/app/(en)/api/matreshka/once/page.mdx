# Matreshka#once

**Method** · Since 1.1

```js
Matreshka#once(names, callback, [context]) → object
```

Adds an event handler which can be called only once

The method works the same as [`Matreshka#on`](/api/matreshka/on/) but the passing handler can be called only once.

> Note that the method has [static alternative](/api/matreshka-static/once/)

**Returns:** [`object`](/api/types/object/) – self

**Fires:** `addevent`, `addevent:NAME`

## Arguments

| Name | Type | Details |
| --- | --- | --- |
| `names` | [`eventNames`](/api/types/event-names/) | An event name or some names which are separated by a space (for example, ``"change:x ajaxcomplete change:y"``) |
| `callback` | [`eventHandler`](/api/types/event-handler/) | A handler which is caused by an event |
| `context` (optional) | [`object`](/api/types/object/) | A context of a handler |

## Examples

```js
this.x = 1;

this.once('change:x', () => {
	alert('x is changed');
});

this.x = 2; // displays 'x is changed'

this.x = 3; // does nothing
```

## Alternative syntax: "eventname-handler" pairs [#variation-2]

```js
Matreshka#once(evtnameHandlerObject, [context]) → object
```

**Returns:** [`object`](/api/types/object/) – self

### Arguments

| Name | Type | Details |
| --- | --- | --- |
| `evtnameHandlerObject` | [`object`](/api/types/object/) | An object where keys are event names and values are event handlers |
| `context` (optional) | [`object`](/api/types/object/) | A context of a handler |

### Links

- [`Matreshka#on(2)`](/api/matreshka/on/#variation-2)

### Examples

```js
this.once({
	'custom': evt => { ... },
	'click::x': evt => { ... },
	'change:y': evt => { ... }
});
```
